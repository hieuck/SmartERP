# Team Discussion Templates

Quick templates để bắt đầu discussion với dev team.

## New Feature

```
@senior-dev @qa-engineer @tech-lead

Feature: [name]
Approach: [description]

Senior Dev: Review architecture
QA: Suggest test cases
Tech Lead: Final decision
```

## Bug Fix

```
@senior-dev @qa-engineer @tech-lead

Bug: [description]
Fix: [approach]

Senior Dev: Root cause analysis
QA: Test cases to prevent
Tech Lead: Priority & timeline
```

## Code Review

```
@senior-dev @qa-engineer @tech-lead

Files: [list]
Changes: [summary]

Senior Dev: Code quality
QA: Test coverage
Tech Lead: Approve/reject
```
