## 🚀 Day 1: Setup & Configuration

### Step 1: Account Creation (15 minutes)

**What You'll Need:**
- Business email address
- Company information
- Payment method (for paid plans)

**Actions:**
1. Go to [smarterp.com/signup](https://smarterp.com/signup)
2. Choose your plan (Free, Starter, Professional, Enterprise)
3. Enter company details:
   - Company name
   - Industry
   - Number of employees
   - Contact information
4. Verify your email
5. Complete payment (if applicable)

**Result:** Your Smart ERP account is created and ready to configure.

---

### Step 2: Initial Configuration (30 minutes)

**Company Settings:**
1. Navigate to Settings > Company
2. Configure:
   - Company name and logo
   - Address and contact details
   - Tax ID and registration numbers
   - Fiscal year settings
   - Currency (VND, USD, etc.)
   - Time zone

**System Settings:**
1. Navigate to Settings > System
2. Configure:
   - Date format (DD/MM/YYYY)
   - Number format
   - Language (Vietnamese/English)
   - Email notifications
   - Default values

**Warehouse Setup:**
1. Navigate to Inventory > Warehouses
2. Create your warehouses:
   - Main warehouse (required)
   - Additional locations (if needed)
   - Set default warehouse

**Categories Setup:**
1. Navigate to Products > Categories
2. Create product categories:
   - Raw materials
   - Finished goods
   - Supplies
   - Custom categories

**Result:** Basic system configuration is complete.

---

### Step 3: User Setup (30 minutes)

**Create User Accounts:**
1. Navigate to Settings > Users
2. Add team members:
   - Full name
   - Email address
   - Role (Admin, Manager, User, Viewer)
   - Department
   - Phone number

**Assign Roles:**
- **Admin**: Full system access
- **Manager**: Department management
- **User**: Daily operations
- **Viewer**: Read-only access

**Set Permissions:**
1. Navigate to Settings > Roles
2. Configure permissions per role:
   - Products: View, Create, Edit, Delete
   - Orders: View, Create, Edit, Delete
   - Customers: View, Create, Edit, Delete
   - Reports: View, Export
   - Settings: View, Edit

**Result:** Team members can now access the system with appropriate permissions.

---

### Step 4: Data Import Preparation (1-2 hours)

**Prepare Your Data:**

**Products Data:**
- Download template: Settings > Import/Export > Products Template
- Required fields:
  - SKU (unique identifier)
  - Name
  - Category
  - Price
  - Cost
  - Stock quantity
  - Low stock threshold
- Optional fields:
  - Description
  - Barcode
  - Weight
  - Dimensions

**Customers Data:**
- Download template: Settings > Import/Export > Customers Template
- Required fields:
  - Name
  - Email or Phone
- Optional fields:
  - Address
  - Tax ID
  - Credit limit
  - Payment terms

**Suppliers Data:**
- Download template: Settings > Import/Export > Suppliers Template
- Required fields:
  - Name
  - Contact information
- Optional fields:
  - Rating
  - Payment terms
  - Lead time
  - Discount

**Inventory Data:**
- Download template: Settings > Import/Export > Inventory Template
- Required fields:
  - Product SKU
  - Warehouse
  - Quantity
- Optional fields:
  - Min quantity
  - Max quantity
  - Reorder point

**Data Quality Checklist:**
- ✅ No duplicate SKUs
- ✅ Valid email addresses
- ✅ Consistent formatting
- ✅ Complete required fields
- ✅ Accurate quantities
- ✅ Correct categories

**Result:** Your data is ready for import.

2. Upload your customers CSV file
3. Map columns to fields
4. Validate data
5. Confirm import

**Import Suppliers:**
1. Navigate to Suppliers > Import
2. Upload your suppliers CSV file
3. Map columns to fields
4. Validate data
5. Confirm import
6. Verify imported suppliers

**Import Inventory:**
1. Navigate to Inventory > Import
2. Upload your inventory CSV file
3. Map columns to fields
4. Validate data
5. Confirm import
6. Verify stock levels

**Common Import Issues:**
- **Duplicate SKUs**: Ensure each product has a unique SKU
- **Invalid emails**: Check email format (name@domain.com)
- **Missing required fields**: Complete all required columns
- **Format errors**: Use the provided templates

**Result:** All your data is now in Smart ERP.

## 🆘 Common Issues & Solutions

### Issue: Can't log in
**Solution:**
1. Check email address is correct
2. Reset password if forgotten
3. Check email for verification link
4. Contact support if still having issues

### Issue: Import fails
**Solution:**
1. Check file format (CSV)
2. Verify required fields are filled
3. Check for duplicate SKUs
4. Use provided templates
5. Contact support with error message

### Issue: Permissions not working
**Solution:**
1. Verify user role is correct
2. Check role permissions in Settings
3. Log out and log back in
4. Clear browser cache
5. Contact support if persists

### Issue: Reports show wrong data
**Solution:**
1. Check date range filters
2. Verify data was imported correctly
3. Check warehouse filters
4. Refresh the report
5. Contact support with screenshot

### Issue: Notifications not received
**Solution:**
1. Check email address in profile
2. Check spam/junk folder
3. Verify notification settings
4. Check email provider isn't blocking
5. Contact support to verify email delivery
